Privacy Policy

rclone-backup / Last updated: October 15, 2026

Data accessed

The app accesses only the files and folders it creates in the owner's Google Drive (Google Drive API scope drive.file). It cannot see any other files.

How data is used

Data is used solely to store and update backup copies of the owner's own files.

Storage

OAuth tokens are stored only on the owner's computer, in the rclone configuration file. No server operated by this app receives or stores any data.

Sharing

No data is shared, sold, or transferred to any third party. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Users

The app is used only by its owner. No data is collected from anyone else.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
